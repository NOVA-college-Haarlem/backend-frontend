# Eindproject Blok 5

## 📋 Wat ga je doen?

Je bouwt deze week een complete CRUD-applicatie voor een toegewezen opdrachtgever, met de technieken uit Hoofdstuk 1 (PDO & Prepared Statements) en Hoofdstuk 2 (Veilige data). Hoofdstuk 3 (Update) is optioneel.

Elke student is al aan één van de zes thema's toegewezen - zie **[Studentverdeling.md](Studentverdeling.md)** voor wie welk thema heeft. Lees daarna de volledige opdracht van jouw thema in **[Eindproject Blok 5.md](Eindproject%20Blok%205.md)** - daar staan het verhaal van de opdrachtgever, de technische eisen en de checklist.

- [Fitness](Fitness.md)
- [Library Management](Library.md)
- [Movie Database](Movie.md)
- [Restaurant](Restaurant.md)
- [Music](Music.md)
- [Figurines](Figurines.md)

## 🚀 Planning van de week

| Dag | Wat |
|-----|-----|
| **Maandag** | Start: bekijk je toegewezen thema, bedenk je databaseontwerp, begin met bouwen |
| **Dinsdag** | Bouwen |
| **Woensdag** | Bouwen |
| **Donderdag** | Laatste bouwdag - **aan het einde van de dag laat je alles aftekenen** door de docent (zie checklist in `Eindproject Blok 5.md`) |
| **Vrijdag** | Mondeling assessment |

> ⚠️ **Donderdag is de deadline om af te tekenen.** Zonder aftekening op donderdag kun je vrijdag niet mondeling beoordeeld worden. Wacht dus niet tot het laatste moment - laat je werk gedurende de week al tussentijds checken.

## ✅ Voorbereiding op het mondeling (vrijdag)

Zorg dat je op vrijdag kan uitleggen:
- Waarom je je database zo hebt ontworpen (welke tabellen, en waar je 1-op-veel/1-op-1 relatie zit)
- Hoe je je code hebt beveiligd (prepared statements, hashing, htmlspecialchars, rolcheck)
- Een willekeurige regel uit je eigen code - wat doet die, en waarom staat die er?
