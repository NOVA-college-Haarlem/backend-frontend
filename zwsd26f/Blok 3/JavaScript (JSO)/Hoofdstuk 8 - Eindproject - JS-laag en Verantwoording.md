## Hoofdstuk 8: Eindproject - JS-laag + Verantwoording

*Docentenhandleiding: `Docent/Hoofdstuk 8 - Docentenhandleiding.md`*

**Taakklasse 3 van 3** - volledige **Make**, op het FEO-eindproject
**PRIMM-fase dit hoofdstuk:** Make + verantwoordingsgesprek

### Projectomschrijving
Afsluitend hoofdstuk van het JS-vak. Je voegt een JS-laag toe aan de website die je in FEO Hoofdstuk 8 als eindproject oplevert. Dezelfde site, nu ook interactief.

### Leerdoelen
Na dit hoofdstuk kan je:
- Zelfstandig JavaScript toevoegen aan een bestaande website
- Meerdere technieken uit dit vak combineren (DOM, events, condities, classList, arrays/loops)
- Een willekeurige regel in je eigen JS-code uitleggen: wat doet die, en waarom staat die er?
- Een stuk (AI-)code controleren op fouten en verbeteren

### Projecteisen (Voldoende)
- [ ] Minimaal 1 werkende `addEventListener`-interactie
- [ ] Minimaal 1 `if`/`else`-conditie die daadwerkelijk invloed heeft op de pagina
- [ ] Minimaal 1 `classList`-toggle (bijv. dark mode, actieve navigatie, of iets eigens)
- [ ] Geen gedupliceerde, bijna-identieke event-handlers - gebruik een array + `forEach` waar dat past
- [ ] Geen `style=`-achtige losse JS-hacks; nette, leesbare code met logische variabelenamen
- [ ] Script gekoppeld via een los `.js`-bestand (geen JS in de HTML)

### Bonus (Goed/Uitstekend)
- [ ] Formulier-feedback (uit Hoofdstuk 7) toegepast op een eigen formulier
- [ ] Meerdere interacties die logisch samenhangen (bijv. een klik die zowel tekst als een class aanpast)
- [ ] Code opgesplitst in kleine, herbruikbare functies

### Programma

**Les 1: Bouwen** - JS-laag toevoegen aan het eigen eindproject (AI mag, mits verantwoordbaar)

**Les 2: Peer review + Debug deze AI-output + polijsten**
- Peer review in tweetallen met de checklist hieronder
- **Debug deze AI-output:** een lap AI-gegenereerde JS met 2-3 ingebouwde fouten - vinden, uitleggen, verbeteren
- Verbeteringen doorvoeren, laatste check met de console (geen foutmeldingen)

**Les 3: Verantwoordingsgesprek**
Kort gesprek per student (5 min), net als bij FEO Hoofdstuk 8:
1. **Demo:** interacties tonen
2. **Toelichting:** welke technieken heb je gebruikt en waarom
3. **Verantwoordingsvraag:** een willekeurige regel JS wordt aangewezen - "wat doet dit, wat gebeurt er als je het weghaalt?"

### Peer Review Checklist
- [ ] Geen foutmeldingen in de console
- [ ] Minstens 1 interactie werkt zichtbaar (klik → iets verandert)
- [ ] Geen drie keer bijna-dezelfde code na elkaar
- [ ] Kun je, als peer, een willekeurige regel JS laten uitleggen door je klasgenoot?

### Beoordelingscriteria

| Criterium | Onvoldoende | Voldoende | Goed |
|---|---|---|---|
| **DOM & events** | Geen werkende interactie | Minstens 1 werkende `addEventListener` | Meerdere, logisch samenhangende interacties |
| **Logica** | Geen condities toegepast | Werkende `if`/`else` met zichtbaar effect | Condities + `classList` samen ingezet |
| **Codekwaliteit** | Gedupliceerde, bijna-identieke handlers | Array + `forEach` waar nodig, nette namen | Herbruikbare functies, overzichtelijke structuur |
| **Verantwoording** | Kan aangewezen regel niet uitleggen | Kan de meeste code uitleggen | Legt keuzes en code overtuigend en zelfstandig uit, ook AI-gegenereerde delen |
