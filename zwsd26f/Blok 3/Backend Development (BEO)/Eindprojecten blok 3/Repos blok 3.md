# Project blok 3

Blok 3A start dit blok vanuit een eigen GitHub-repository voor Boulder Base (net als bij `mijn-eerste-project` en `formula1-2526`), niet meer vanuit het eigen FEO/JSO-eindproject. De inhoud van `boulderbase-start/` (zie `Project_Blok3A.md`) - inclusief `docker-compose.yml` en `sql/lessen.sql` - staat al klaar in die repository. Studenten forken en clonen deze repo, en hoeven zelf geen omgeving of databasetabel op te zetten. Blok 3B (zie `Project_Blok3B.md`) bouwt vervolgens verder op wat er in Blok 3A in die eigen repository is gemaakt.
